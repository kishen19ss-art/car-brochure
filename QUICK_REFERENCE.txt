🎯 FASTEST PATH TO DEPLOYMENT (5 minutes)
================================================================================

STEP 1: Update vite.config.ts (line 8)
--------------------------------------
Change: base: process.env.GITHUB_ACTIONS ? '/car-brochure/' : '/',
To:     base: process.env.GITHUB_ACTIONS ? '/YOUR-REPO-NAME/' : '/',


STEP 2: Create GitHub Repo
---------------------------
1. Go to github.com
2. Click "+" → "New repository"
3. Name: your-repo-name (same as Step 1)
4. Visibility: Public
5. Click "Create repository"


STEP 3: Push Code
------------------
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git
git branch -M main
git push -u origin main


STEP 4: Enable GitHub Pages
----------------------------
1. Go to repository Settings
2. Click "Pages" in sidebar
3. Source: Select "GitHub Actions"
4. Done!


STEP 5: Wait (1-2 minutes)
---------------------------
1. Go to Actions tab
2. Wait for green checkmark ✅
3. Your site is live!

Your URL: https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/

================================================================================
❓ TROUBLESHOOTING
================================================================================

Blank page or 404:
  → Check vite.config.ts base path matches repo name exactly

Build fails:
  → Run npm install locally first
  → Check Actions tab for error details

Images not loading:
  → Check internet connection (images from Unsplash)

GitHub Actions not running:
  → Make sure Pages source is "GitHub Actions"
  → Check repository is Public
