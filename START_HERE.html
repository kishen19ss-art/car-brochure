Quick Setup Guide

Step 1️⃣: Install Node.js

Download and install Node.js from the official website:

Download Node.js

Choose the LTS (Long Term Support) version. This includes npm, which you'll need for the next steps.

Step 2️⃣: Open Terminal/Command Prompt

Windows: Press Win + R, type cmd, press Enter

Mac: Press Cmd + Space, type "terminal", press Enter

Linux: Press Ctrl + Alt + T

Step 3️⃣: Navigate to Project Folder

Use the cd command to navigate to this project folder:

cd path/to/car-brochure-folder

Example:

cd C:\Users\YourName\Downloads\car-brochure

Step 4️⃣: Install Dependencies

Run this command (only needed once):

npm install

This will download all required libraries and packages.

Step 5️⃣: Start Development Server

Run this command:

npm run dev

Then open your browser and visit:

http://localhost:5173

🎉 Your application will now be running!

📦 Building for Production

Option 1: Deploy to GitHub Pages (Recommended)

🌐 Make your site live on the internet without localhost!

For detailed step-by-step instructions, open:

📖 GitHub Deployment Guide

Quick Summary:

  1. Update vite.config.ts with your repo name
  2. Create a GitHub repository
  3. Push your code to GitHub
  4. Enable GitHub Pages (Source: GitHub Actions)
  5. Your site will be live at https://username.github.io/repo-name/

Option 2: Create Local Production Build

To create static files for manual deployment:

npm run build

This creates a dist folder with all your HTML, CSS, and JavaScript files ready to upload to any web hosting service.

❓ Troubleshooting

Common Issues

Problem: "npm: command not found"

Solution: Install Node.js first (Step 1)

Problem: Port already in use

Solution: Run npm run dev -- --port 3000

Problem: Blank page after building

Solution: Use a web server to serve the dist folder (see BUILD_INSTRUCTIONS.txt)

For detailed instructions, see:

BUILD_INSTRUCTIONS.txt or README.md
